Capabilities

Everything You Need to Ship Agents

One CLI to provision infrastructure, wire bindings, and keep everything in sync.

Single Command Deploy

Create Discord categories, text channels, and OpenClaw agent bindings in one atomic operation. No manual clicking through Discord settings.

Project-Scoped Agents

Prefix agent IDs with project names automatically while reusing shared bot accounts across multiple projects. Clean isolation without duplication.

Plan & Dry Run

Preview every mutation before it happens. See exactly which channels will be created, which bindings will be wired, and which files will be written.

Drift Detection & Sync

Detect configuration drift between your state file and actual Discord/OpenClaw state. Reconcile with a single sync command.

Atomic & Safe

Config writes use atomic temp-file swaps. Backups are created before every mutation. State is machine-global for repeatable operations across projects.

YAML Manifests

Define channel-to-agent mappings in version-controlled YAML files. Share project configurations across teams and environments.
